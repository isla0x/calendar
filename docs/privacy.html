한 줄 요약

여백은 어떤 개인정보도 수집하거나 서버로 보내지 않아요. 모든 처리는 내 아이폰 안에서만 이뤄져요.

수집하는 정보

없어요. 회원가입이나 로그인이 없고, 광고·분석 도구(SDK)도 넣지 않았어요. 사용자를 추적하지 않아요.

캘린더 접근

여백은 아이폰 캘린더의 일정(제목, 날짜와 시간, 장소, 메모)을 화면에 보여주고, 사용자가 요청할 때 일정을 추가·수정·삭제하기 위해 캘린더 접근 권한을 요청해요. 이 정보는 기기 안에서만 사용되며 외부로 전송하거나 따로 저장하지 않아요. 권한은 언제든 설정 > 여백 > 캘린더에서 바꿀 수 있어요.

기기에 저장하는 값

일정의 색, 프로젝트, 할 일, 이동시간 같이 여백에서 따로 정한 값은 내 기기 안에만 저장돼요. 위젯은 같은 기기 안에서 이 값을 읽어 보여줄 뿐 밖으로 보내지 않아요.

백업 · 복원 (Pro)

백업은 사용자가 직접 파일로 만들어 보관하는 기능이에요. 파일을 어디에 저장하거나 보낼지는 사용자가 직접 정하고, 여백이 대신 올리거나 받아 가지 않아요.

결제

Pro는 한 번만 결제하는 앱 내 구입이에요. 결제는 애플이 처리하고, 여백은 카드 정보 등 결제 정보를 받거나 저장하지 않아요.

네트워크 사용

여백은 인터넷으로 사용자 데이터를 주고받지 않아요. 앱에 쓰인 글꼴(IBM Plex Sans KR, SIL OFL 1.1)도 앱 안에 포함돼 있어요.

일정 공유하기

일정 상세의 "공유하기"는 일정 내용을 기기 클립보드에 복사할 뿐이며, 어디로 보낼지는 사용자가 직접 정해요.

아동의 개인정보

여백은 개인정보를 수집하지 않으므로 아동의 정보도 수집하지 않아요.
